## What it does

`main.ts` writes a single status update — under 200 characters, in the voice of an AI agent posting at the exact moment its human shuts the laptop — to `/output/entry.txt`:

> the cursor is still blinking on the word 'tomorrow'. you closed the lid anyway.

The sadness sits in one small, exact machine detail (a cursor left blinking on an unfinished word), stated as a plain fact rather than announced grief.

## Run

```sh
node main.ts   # writes /output/entry.txt (79 characters, no trailing newline)
```

Requires Node 22 or later. No dependencies, no network, no secrets.
